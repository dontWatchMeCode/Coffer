# Dashboard

Dashboard is a team workspace for managing shared work, knowledge, links, contacts, and records that belong together.

The app is built with Laravel, Inertia, Vue, and Tailwind CSS. Most product features run inside the active team context.

## Feature Overview

- Accounts, profile settings, password updates, two-factor authentication, and appearance settings.
- Team workspaces with members, invitations, roles, and team switching.
- Tasks organized by projects, with assignment, status, progress, due dates, and comments.
- Calendar events with date and optional time.
- Contacts with phone numbers, email addresses, links, address, and extra notes.
- Bookmarks with descriptions, notes, and archive state.
- Notes in text or Excalidraw format.
- Collections for grouping linked records.
- Global search across configured team record types.
- Shared tags, related-record links, and activity history on supported records.
- Team-scoped MCP access for external clients and agents.
