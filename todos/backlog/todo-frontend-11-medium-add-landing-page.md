# Add Marketing Landing Page

Add a public marketing landing page for unauthenticated visitors, SSR or statically rendered.

## Scope

- Public-facing page at the root URL (when not authenticated)
- Product overview, features, CTA (sign up / log in)
- SEO-friendly (meta tags, OG tags, semantic HTML)
- SSR or statically rendered for fast load and SEO

## Acceptance Criteria

- [ ] Design landing page layout (hero, features, CTA sections)
- [ ] Set up SSR or static rendering for the landing page
- [ ] Add SEO meta tags (title, description, OG tags)
- [ ] Add navigation links to sign up and log in
- [ ] Ensure responsive design
- [ ] Ensure landing page does not require authentication
- [ ] Redirect authenticated users to their team dashboard
